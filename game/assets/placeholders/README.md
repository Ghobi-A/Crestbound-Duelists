# Placeholder Art

Everything in the prototype is **programmer art**: original coloured
blocks, silhouettes, and panels drawn in code from `palette.gd`.

Rules:

- No copyrighted game assets, ever.
- All placeholder visuals draw their colours from `palette.gd` so the
  look can be retuned in one place.
- Final art replaces placeholder *drawing code* with 16x16 sprites and
  tiles under `assets/sprites/` and `assets/tiles/` — scene structure
  should not need to change.

Target for final art: original Game Boy Color / late-16-bit-inspired
pixel art. 16x16 tiles, ~16x16 or 16x24 character footprints, 320x180
internal canvas.
